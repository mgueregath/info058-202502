    Banco de Ejercicios · Bucle for (solo ejercicios)¶

    Cada ejercicio explica claramente el requerimiento.
    La solución está oculta en un bloque desplegable.
    Cuando se usa algo fuera de for, if, else, input, int, float, str, range, print, se incluye una nota rápida.

    A. for con if¶

    E1. Contar positivos en una lista¶

    Requerimiento:
    - Lee una línea con números enteros separados por espacio.
    - Recorre la lista con for y cuenta cuántos son mayores que 0.
    - Imprime solo el conteo (un número entero).

    Ejemplo (entrada): 

    -1 0 5 3 -2 7
    Salida (ejemplo): 
    3

    Ver solución 
    nums = list(map(int, input().split()))
cont = 0
for x in nums:
    if x > 0:
        cont += 1
print(cont)

    E2. Múltiplos de 3 del 1 al 30¶

    Requerimiento:
    - Recorre los números del 1 al 30 con for.
    - Imprime solo los que sean múltiplos de 3 (uno por línea).

    Salida (ejemplo): 

    3
6
9
12
15
18
21
24
27
30

    Ver solución 
    for n in range(1, 31):
    if n % 3 == 0:
        print(n)

    E3. Extraer mayúsculas de un texto¶

    Requerimiento:
    - Lee un texto.
    - Recorre caracter por caracter e imprime solo las letras mayúsculas (una por línea).

    Ejemplo (entrada): Hola Mundo PY
    Salida (ejemplo): 

    H
M
P
Y

    Ver solución 
    t = input()
for ch in t:
    if ch.isupper():
        print(ch)

    E4. Suma de pares hasta n¶

    Requerimiento:
    - Lee un entero n.
    - Suma solo los pares entre 1 y n inclusive.
    - Imprime la suma.

    Ejemplo (entrada): 10
    Salida (ejemplo): 30

    Ver solución 
    n = int(input())
s = 0
for x in range(1, n + 1):
    if x % 2 == 0:
        s += x
print(s)

    E5. Contar letras 'a' o 'A' sin listas externas¶

    Requerimiento:
    - Lee un texto.
    - Recorre con for y cuenta cuántas veces aparece 'a' o 'A'.
    - Imprime el conteo. (No uses colecciones externas de vocales).

    Ejemplo (entrada): Abracadabra
    Salida (ejemplo): 5

    Ver solución 
    t = input()
c = 0
for ch in t:
    if ch == 'a' or ch == 'A':
        c += 1
print(c)

    B. for con if + else¶

    E6. Par o impar por elemento¶

    Requerimiento:
    - Lee enteros separados por espacio.
    - Para cada número, imprime "{n}: par" si es par, de lo contrario "{n}: impar".

    Salida (ejemplo): 

    2: par
7: impar
0: par

    Ver solución 
    nums = list(map(int, input().split()))
for n in nums:
    if n % 2 == 0:
        print(f"{n}: par")
    else:
        print(f"{n}: impar")

    E7. Clasificar signo¶

    Requerimiento:
    - Lee enteros separados por espacio.
    - Imprime OK si n >= 0, si no imprime NEG.

    Salida (ejemplo): 

    -3 NEG
0 OK
5 OK

    Ver solución 
    nums = list(map(int, input().split()))
for n in nums:
    if n >= 0:
        print(n, "OK")
    else:
        print(n, "NEG")

    E8. Enmascarar dígitos¶

    Requerimiento:
    - Lee un texto.
    - Recorre cada caracter: si es dígito, imprime *; si no, imprime el caracter original (misma línea, sin espacios extra).

    Ejemplo (entrada): abc12x9
    Salida (ejemplo): abc**x*

    Ver solución 
    t = input()
res = ""
for ch in t:
    if ch.isdigit():
        res += "*"
    else:
        res += ch
print(res)

    E9. Conservar solo letras¶

    Requerimiento:
    - Lee un texto.
    - Recorre el texto y construye otro que contenga únicamente letras (sin números ni símbolos).
    - Imprime el resultado.

    Ejemplo (entrada): Py3.11 es genial!
    Salida (ejemplo): Pyesgenial

    Ver solución 
    t = input()
res = ""
for ch in t:
    if ch.isalpha():
        res += ch
print(res)

    E10. Aprobado/Reprobado¶

    Requerimiento:
    - Lee 5 notas decimales (separadas por espacio).
    - Para cada una, imprime APROBADO si nota >= 4.0, si no, REPROBADO.

    Ver solución 
    notas = list(map(float, input().split()))
for n in notas[:5]:
    if n >= 4.0:
        print("APROBADO")
    else:
        print("REPROBADO")

    C. for con if + elif + else¶

    E11. Tramos de edad¶

    Requerimiento:
    - Lee edades enteras separadas por espacio.
    - Para cada edad imprime:
    - NIÑO si 0–12,
    - ADOLESCENTE si 13–17,
    - ADULTO si >=18.

    Ver solución 
    edades = list(map(int, input().split()))
for e in edades:
    if 0 <= e <= 12:
        print("NIÑO")
    elif 13 <= e <= 17:
        print("ADOLESCENTE")
    else:
        print("ADULTO")

    E12. Categoría de nota (1–7)¶

    Requerimiento:
    - Lee notas (1.0 a 7.0).
    - Imprime: INSUFICIENTE (<4.0), BUENO (>=4.0 y <6.0), EXCELENTE (>=6.0).

    Ver solución 
    notas = list(map(float, input().split()))
for n in notas:
    if n < 4.0:
        print("INSUFICIENTE")
    elif n < 6.0:
        print("BUENO")
    else:
        print("EXCELENTE")

    E13. Contar negativos, ceros y positivos¶

    Requerimiento:
    - Lee enteros separados por espacio.
    - Recorre y cuenta cuántos son negativos, ceros y positivos.
    - Imprime los tres conteos en ese orden.

    Salida (ejemplo): 

    negativos: 2
ceros: 1
positivos: 3

    Ver solución 
    nums = list(map(int, input().split()))
neg = cer = pos = 0
for n in nums:
    if n < 0:
        neg += 1
    elif n == 0:
        cer += 1
    else:
        pos += 1
print("negativos:", neg)
print("ceros:", cer)
print("positivos:", pos)

    E14. Tipo de caracter: letra / dígito / otro¶

    Requerimiento:
    - Lee un texto.
    - Para cada caracter, imprime: LETRA si es letra, DÍGITO si es dígito, OTRO en cualquier otro caso.

    Ver solución 
    t = input()
for ch in t:
    if ch.isalpha():
        print("LETRA")
    elif ch.isdigit():
        print("DÍGITO")
    else:
        print("OTRO")

    E15. Descuento por monto¶

    Requerimiento:
    - Lee montos enteros (uno o varios).
    - Para cada monto, determina descuento:
    - < 20000: 0%
    - 20000–49999: 5%
    - >= 50000: 10%
    - Imprime monto, %desc y total (monto - descuento).

    Ver solución 
    montos = list(map(int, input().split()))
for m in montos:
    if m < 20000:
        d = 0.0
    elif m < 50000:
        d = 0.05
    else:
        d = 0.10
    total = int(round(m * (1 - d)))
    print(m, int(d*100), "%", total)

    D. for anidado¶

    E16. Tabla n x m¶

    Requerimiento:
    - Lee dos enteros n y m.
    - Imprime una tabla con n filas y m columnas con el formato i,j (índices 1-based).

    Ejemplo (entrada): 2 3
    Salida (ejemplo): 

    1,1  1,2  1,3
2,1  2,2  2,3

    Ver solución 
    n, m = map(int, input().split())
for i in range(1, n + 1):
    fila = []
    for j in range(1, m + 1):
        fila.append(f"{i},{j}")
    print("  ".join(fila))

    E17. Rectángulo de #¶

    Requerimiento:
    - Lee alto h y ancho w.
    - Dibuja un rectángulo sólido de # de h filas por w columnas.

    Ver solución 
    h, w = map(int, input().split())
for _ in range(h):
    linea = ""
    for _ in range(w):
        linea += "#"
    print(linea)

    E18. Triángulo creciente¶

    Requerimiento:
    - Lee n.
    - Imprime un triángulo de asteriscos con n filas, donde la fila i tiene i asteriscos.

    Ver solución 
    n = int(input())
for i in range(1, n + 1):
    linea = ""
    for _ in range(i):
        linea += "*"
    print(linea)

    E19. Combinaciones de dos listas¶

    Requerimiento:
    - Dadas dos listas A y B (define algunos valores), imprime todas las combinaciones a-b para a en A y b en B.

    Nota rápida:
    - Lista: estructura que guarda elementos en orden. Se escribe entre corchetes, por ejemplo: A = ["rojo", "azul"].
    - Puedes recorrerla con for y acceder por índice (0, 1, 2, ...).

    Salida (ejemplo): 

    rojo-S  rojo-M  rojo-L
azul-S  azul-M  azul-L

    Ver solución 
    A = ["rojo", "azul"]
B = ["S", "M", "L"]
for a in A:
    fila = []
    for b in B:
        fila.append(f"{a}-{b}")
    print("  ".join(fila))

    E20. Matriz con consecutivos¶

    Requerimiento:
    - Lee n y m.
    - Construye una matriz con números consecutivos desde 1 hasta n*m, por filas.
    - Imprime cada fila en una línea.

    Nota rápida:
    - Matriz: comúnmente se representa como lista de listas. Cada sublista es una fila.
    Ejemplo (2x3): [[1,2,3],[4,5,6]]. Se recorre con for anidado.

    Ejemplo (entrada): 2 4
    Salida (ejemplo): 

    1 2 3 4
5 6 7 8

    Ver solución 
    n, m = map(int, input().split())
cnt = 1
for _ in range(n):
    fila = []
    for _ in range(m):
        fila.append(str(cnt))
        cnt += 1
    print(" ".join(fila))

    E. for anidados con if¶

    E21. Matriz identidad n x n¶

    Requerimiento:
    - Lee n.
    - Imprime la matriz identidad: 1 cuando i == j, si no 0.

    Nota rápida:
    - Matriz identidad: cuadrada con 1 en la diagonal principal y 0 en el resto.

    Salida (ejemplo para n=3): 

    1 0 0
0 1 0
0 0 1

    Ver solución 
    n = int(input())
for i in range(n):
    fila = []
    for j in range(n):
        if i == j:
            fila.append("1")
        else:
            fila.append("0")
    print(" ".join(fila))

    E22. Triángulo superior (i < j)¶

    Requerimiento:
    - Lee n.
    - Recorre todas las parejas (i,j) con 0 <= i,j < n.
    - Imprime solo las parejas donde i < j.

    Ver solución 
    n = int(input())
for i in range(n):
    for j in range(n):
        if i < j:
            print(i, j)

    E23. Marco hueco¶

    Requerimiento:
    - Lee alto h y ancho w.
    - Dibuja un marco de * con interior vacío (espacios).
    - Bordes con *, interior con espacios.

    Ejemplo (entrada): 4 6
    Salida (ejemplo): 

    ******
*    *
*    *
******

    Ver solución 
    h, w = map(int, input().split())
for i in range(h):
    linea = ""
    for j in range(w):
        if i in (0, h - 1) or j in (0, w - 1):
            linea += "*"
        else:
            linea += " "
    print(linea)

    E24. Tabla con múltiplos marcados¶

    Requerimiento:
    - Lee n.
    - Imprime una tabla n x n con los números 1..n*n por filas.
    - Si el número es múltiplo de 3, imprime X en su lugar.

    Salida (ejemplo para n=4): 

    1 2 X 4
5 X 7 8
X 10 11 X
13 14 X 16

    Ver solución 
    n = int(input())
val = 1
for _ in range(n):
    fila = []
    for _ in range(n):
        if val % 3 == 0:
            fila.append("X")
        else:
            fila.append(str(val))
        val += 1
    print(" ".join(fila))

    E25. Ventas sobre la meta (listas anidadas)¶

    Requerimiento:
    - Dada una estructura de ventas por sucursal (lista de listas), donde cada sublista son las ventas diarias de una sucursal:
    ventas = [[10, 20, 5], [8, 12, 15], [30, 25, 10]]
    - Lee una meta entera.
    - Recorre sucursales y días con for anidados.
    - Imprime Sucursal i - Día j: venta solo si la venta es >= meta.
    (Índices 1-based en la impresión.)

    Nota rápida:
    - Lista de listas: cada elemento de la lista principal es otra lista (una fila/colección). Se recorre con dos for.

    Ver solución 
    ventas = [[10, 20, 5], [8, 12, 15], [30, 25, 10]]
meta = int(input())
for i in range(len(ventas)):
    for j in range(len(ventas[i])):
        if ventas[i][j] >= meta:
            print(f"Sucursal {i+1} - Día {j+1}: {ventas[i][j]}")
