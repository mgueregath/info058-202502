    Banco de Ejercicios¶

    Enfoque: Secuencia simple, if/elif/else (principal) y for (ampliado).
    Formato estilo evaluación: V/F, alternativas, completar condición/código, predecir salida.
    Respuestas: cada ejercicio incluye un bloque desplegable <details> para verificar la solución. Usa Python 3.

    Recomendación: intenta resolver sin ver la respuesta. Luego expande <details> para autoverificar.

    Parte A · Secuencia simple (12)¶

    Ejercicios introductorios sin usar if ni for. Incluyen código base para que pegues y pruebes.

    A1. Saludo simple – Solicita un nombre y muestra Hola, <nombre>! 

    nombre = input("Nombre: ")
print(f"Hola, {nombre}!")

    Ver respuestaImprime el saludo con el nombre ingresado.

    A2. Suma de enteros – Lee dos enteros y muestra su suma. 

    a = int(input("A: "))
b = int(input("B: "))
print(a + b)

    Ver respuestaSalida = A + B.

    A3. Área de rectángulo – Ingresa base y altura; muestra el área con 2 decimales. 

    base = float(input("Base: "))
altura = float(input("Altura: "))
area = base * altura
print(f"{area:.2f}")

    Ver respuestaÁrea = base × altura.

    A4. °C → °F – Convierte °C a °F. 

    c = float(input("°C: "))
f = c * 9/5 + 32
print(f"{f:.2f}")

    Ver respuestaFórmula: F = C×9/5 + 32.

    A5. Velocidad media – Pide distancia (km) y tiempo (h); muestra km/h. 

    km = float(input("Km: "))
h  = float(input("Horas: "))
vm = km / h
print(f"{vm:.2f} km/h")

    Ver respuestaVelocidad = km / h.

    A6. Neto→Bruto – Ingresa neto y %IVA; muestra el precio bruto. 

    neto = float(input("Neto: "))
iva  = float(input("% IVA: ")) / 100
bruto = neto * (1 + iva)
print(f"{bruto:.2f}")

    Ver respuestaBruto = neto × (1 + IVA/100).

    A7. Entera y decimal – Pide un real y muestra su parte entera y decimal. 

    x = float(input("Número: "))
ent = int(x)
dec = x - ent
print(ent, f"{dec:.3f}")

    Ver respuestaMuestra parte entera y fracción (aprox.).

    A8. Minutos → h:min – Convierte minutos a horas y minutos. 

    m = int(input("Minutos: "))
h = m // 60
r = m % 60
print(f"{h} h {r} min")

    Ver respuestaUsa división entera y módulo.

    A9. IMC – IMC = peso/(altura^2), 2 decimales. 

    peso = float(input("Peso (kg): "))
alt  = float(input("Altura (m): "))
imc = peso / (alt ** 2)
print(f"{imc:.2f}")

    Ver respuestaMuestra IMC con dos decimales.

    A10. MB→KB→bytes (base 1024) 

    mb = float(input("MB: "))
kb = mb * 1024
by = kb * 1024
print(f"{kb:.2f} KB  {int(by)} bytes")

    Ver respuesta1 MB = 1024 KB; 1 KB = 1024 bytes.

    A11. ms/frame → fps – fps ≈ 1000/ms. 

    ms = float(input("ms por frame: "))
fps = 1000 / ms
print(f"{fps:.1f} fps")
``>

    B4) Completar condición/código (14)¶

    B4.1. “Negativo” si n es menor que 0.

    Ver respuesta`if n < 0: print("Negativo")`

    B4.2. “Par” si divisible por 2, si no “Impar”.

    Ver respuesta 
    if n % 2 == 0:
    print("Par")
else:
    print("Impar")

    B4.3. “M3 y M5” si múltiplo de 3 y 5; otro “Otro”.

    Ver respuesta 
    if n % 3 == 0 and n % 5 == 0:
    print("M3 y M5")
else:
    print("Otro")

    B4.4. Edad → <12: Niño, 12–17: Adolescente, >=18: Adulto.

    Ver respuesta 
    if edad < 12:
    print("Niño")
elif edad <= 17:
    print("Adolescente")
else:
    print("Adulto")

    B4.5. Nota (1.0–7.0): >=6.0 Excelente, >=4.0 Aprobado, otro Reprobado.

    Ver respuesta 
    if nota >= 6.0:
    print("Excelente")
elif nota >= 4.0:
    print("Aprobado")
else:
    print("Reprobado")

    B4.6. Si x en [10, 20] → “Rango”; otro “Fuera”.

    Ver respuesta`if 10 <= x <= 20: print("Rango") else: print("Fuera")`

    B4.7. Triángulo isósceles si a == b y b == c.

    Ver respuesta`if a == b == c: print("Tri-Iso") else: print("Otro")` *(nota: eso es equilátero; si querías isósceles: `a==b or a==c or b==c`)*

    B4.8. Leer tres números y mostrar el mayor.

    Ver respuesta 
    a = float(input()); b = float(input()); c = float(input())
if a >= b and a >= c: print(a)
elif b >= a and b >= c: print(b)
else: print(c)

    B4.9. Año bisiesto (simplificado: divisible por 4).

    Ver respuesta`if anio % 4 == 0: print("Bisiesto") else: print("No")`

    B4.10. prom >= 5.5 → "Beca", >=4.0 → "Regular", otro "Reprobado".

    Ver respuesta 
    if prom >= 5.5: print("Beca")
elif prom >= 4.0: print("Regular")
else: print("Reprobado")

    B4.11. x == 0 → "Cero", x > 0 → "Positivo", otro "Negativo".

    Ver respuesta 
    if x == 0: print("Cero")
elif x > 0: print("Positivo")
else: print("Negativo")

    B4.12. Clave “python123” → OK; otro DENEGADO.

    Ver respuesta`print("OK" if clave == "python123" else "DENEGADO")`

    B4.13. n en {1,3,5,7,9} → “Impar chico”; en {2,4,6,8} “Par chico”; otro “Otro”.

    Ver respuesta 
    if n in {1,3,5,7,9}: print("Impar chico")
elif n in {2,4,6,8}: print("Par chico")
else: print("Otro")

    B4.14. Dos horas (0–23) en mismo turno: mañana [6–11], tarde [12–19], noche [20–5].

    Ver respuesta 
    def turno(h):

    B5) Programación breve (12)¶

    B5.1. Entero → positivo/negativo/cero.

    Ver respuestaUsa `if/elif/else` comparando con 0.

    B5.2. Entero → par/impar.

    Ver respuesta`print("par" if n % 2 == 0 else "impar")`

    B5.3. Dos enteros → mayor o “iguales”.

    Ver respuestaCompara `a` vs `b` con `>` y `==`.

    B5.4. Tres enteros → menor.

    Ver respuestaEncadena comparaciones o usa variables auxiliares.

    B5.5. Puntaje 0–100 → 1.0–7.0 lineal + “aprobado” si ≥4.0.

    Ver respuesta`nota = 1 + (p/100)*6; print("aprobado" if nota>=4 else "reprobado")`

    B5.6. Precio + cupón "DESC10"|"DESC20" → aplica % o 0%.

    Ver respuestaNormaliza cupón y aplica `precio*(1-desc)`.

    B5.7. Tarifa por edad: <12:$1000, 12–65:$2000, >65:$1500.

    Ver respuestaUsa `if edad < 12 ... elif edad <= 65 ... else ...`

    B5.8. Envío por peso: <1kg:$2000, 1–5:$4000, >5:$7000.

    Ver respuestaEncadena `if/elif/else` por rangos.

    B5.9. Temperatura: <0 "Bajo cero", 0–30 "Normal", >30 "Calor".

    Ver respuestaAtiende el límite 0/30 con `<=`.

    B5.10. Tipo de triángulo por lados.

    Ver respuestaEquilátero si `a==b==c`; isósceles si `a==b or a==c or b==c`; si no, escaleno.

    B5.11. Verifica usuario/clave (valores fijos).

    Ver respuestaCompara cadenas con `==`; cuida mayúsculas/minúsculas.

    B5.12. Semáforo: "rojo"|"amarillo"|"verde" → acción.

    Ver respuestaNormaliza con `.lower()` y usa `if/elif/else`.
