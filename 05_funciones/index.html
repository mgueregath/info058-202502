    🧩 Clase: Funciones en Python (Parte 1 y 2)¶

    🔹 PARTE 1 — Concepto y fundamentos¶

    🎯 Objetivos¶

    • Comprender qué es una función y su utilidad.
    • Relacionar las funciones matemáticas con las funciones en programación.
    • Aprender a definir funciones con y sin return.
    • Practicar funciones básicas en Python.

    🧠 1. ¿Qué es una función?¶

    Una función es un bloque de código reutilizable que realiza una tarea específica.
    Se puede ejecutar (llamar) muchas veces sin reescribir el mismo código.

    📊 Ejemplo matemático:

    [ f(x) = x^2 + 1 ]

    En Python:

    def f(x):
    return x**2 + 1

print(f(2))  # → 5

    ⚙️ 2. Estructura básica de una función¶

    def nombre_funcion(parámetros):
    # bloque de código
    return resultado_opcional

    Notas: - Los parámetros son los datos de entrada. - return devuelve un valor a quien llama a la función (opcional). - Si no hay return, la función devuelve None por defecto.

    📘 Ejemplo 1 — Sin parámetros ni retorno¶

    def saludar():
    print("Hola, bienvenido a la clase de Python!")

saludar()

    📘 Ejemplo 2 — Con parámetros¶

    def saludar(nombre):
    print(f"Hola {nombre}, ¡bienvenido!")

saludar("Mirko")

    📘 Ejemplo 3 — Con return¶

    def sumar(a, b):
    return a + b

resultado = sumar(3, 5)
print("La suma es:", resultado)

    📘 Ejemplo 4 — Con valores por defecto¶

    def potencia(base, exponente=2):
    return base ** exponente

print(potencia(5))     # 25
print(potencia(2, 3))  # 8

    📘 Ejemplo 5 — Documentación con docstring¶

    def celsius_a_fahrenheit(c):
    """Convierte grados Celsius a Fahrenheit.
    Fórmula: F = C * 9/5 + 32
    """
    return c * 9/5 + 32

    🔹 PARTE 2 — Funciones avanzadas y aplicación práctica¶

    🎯 Objetivos¶

    • Usar funciones para resolver problemas más complejos.
    • Combinar condiciones, bucles y llamadas entre funciones.
    • Comprender el uso de return en flujos de decisión.
    • Escribir funciones puras y reutilizables.

    ⚙️ Ejemplo 1 — Función dentro de otra¶

    def cuadrado(x):
    return x ** 2

def suma_cuadrados(a, b):
    return cuadrado(a) + cuadrado(b)

print(suma_cuadrados(2, 3))  # → 13

    ⚙️ Ejemplo 2 — Funciones con condiciones¶

    def evaluar_nota(nota):
    if nota >= 4.0:
        return "Aprobado"
    else:
        return "Reprobado"

print(evaluar_nota(3.5))

    ⚙️ Ejemplo 3 — Función con bucle¶

    def imprimir_tabla(n):
    for i in range(1, 11):
        print(f"{n} x {i} = {n*i}")

imprimir_tabla(7)

    ⚙️ Ejemplo 4 — Función con validación simple¶

    def dividir(a, b):
    if b == 0:
        return "Error: división por cero"
    return a / b

print(dividir(10, 2))
print(dividir(5, 0))

    💡 Ejercicio 4¶

    Combina ambas funciones del ejercicio anterior en una sola función evaluar_imc.

    💡 Mostrar solución 
    def evaluar_imc(peso, altura):
    imc = peso / (altura ** 2)
    if imc < 18.5:
        estado = "Bajo peso"
    elif imc < 25:
        estado = "Normal"
    elif imc < 30:
        estado = "Sobrepeso"
    else:
        estado = "Obesidad"
    return f"IMC: {imc:.2f} ({estado})"

print(evaluar_imc(70, 1.75))

    💡 Ejercicio 17 (conteo de caracteres)¶

    Crea frecuencia_caracteres(s) que retorne un diccionario {caracter: cantidad}.

    💡 Mostrar solución 
    def frecuencia_caracteres(s):
    freq = {}
    for ch in s:
        freq[ch] = freq.get(ch, 0) + 1
    return freq

print(frecuencia_caracteres("banana"))

    💡 Ejercicio 18 (selección múltiple)¶

    Crea nota_en_letra(n) que convierta una nota numérica a letra: - >= 6.0: "Excelente" - >= 5.0: "Bueno" - >= 4.0: "Suficiente" - < 4.0: "Insuficiente"

    💡 Mostrar solución 
    def nota_en_letra(n):
    if n >= 6.0:
        return "Excelente"
    elif n >= 5.0:
        return "Bueno"
    elif n >= 4.0:
        return "Suficiente"
    else:
        return "Insuficiente"

print(nota_en_letra(5.6), nota_en_letra(3.9))

    💡 Ejercicio 19 (anidación)¶

    Crea promedio3(a,b,c), clasificar(prom) y evaluar(a,b,c) que use ambas.

    💡 Mostrar solución 
    def promedio3(a, b, c):
    return (a + b + c) / 3

def clasificar(prom):
    return "Aprobado" if prom >= 4 else "Reprobado"

def evaluar(a, b, c):
    prom = promedio3(a, b, c)
    return f"Promedio: {prom:.2f} → {clasificar(prom)}"

print(evaluar(5.5, 6.0, 3.5))

    💡 Ejercicio 20 (desafío)¶

    Crea estadisticas(lista) que retorne un dict con: promedio, máximo, mínimo y cantidad.

    💡 Mostrar solución 
    def estadisticas(lista):
    total = sum(lista)
    n = len(lista)
    return {
        "promedio": total / n if n else 0,
        "max": max(lista) if n else None,
        "min": min(lista) if n else None,
        "cantidad": n
    }

print(estadisticas([5, 2, 7, 9, 3]))
