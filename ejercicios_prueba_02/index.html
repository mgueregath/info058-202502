    1) Sumatoria 1..N¶

    Escriba un codigo en python que solicite el ingreso de un número N y calcule la sumatoria desde 1 hasta N.

    Mostrar solución 
    n = int(input("N: "))
s = 0
for i in range(1, n+1):
    s += i
print(s)

    Salida esperada (ejemplo)
    Entrada: N: 5 → Salida: 15

    2) Concatenar N letras¶

    Escriba un codigo en python que solicite un número N, luego pida N letras e imprima un solo texto con las letras juntas.

    Mostrar solución 
    n = int(input("N: "))
salida = ""
for i in range(n):
    ch = input("Letra: ")
    salida += ch
print(salida)

    6) Factorial con while¶

    Escriba un codigo en python que pida N (entero ≥ 0) y calcule N! con un while.

    Mostrar solución 
    n = int(input("N: "))
res = 1
i = 1
while i <= n:
    res *= i
    i += 1
print(res)

    Salida esperada (ejemplo)
    Entrada: N: 5 → Salida: 120

    7) Contar dígitos¶

    Escriba un codigo en python que pida un entero y cuente cuántos dígitos tiene (sin convertir a lista).

    Mostrar solución 
    n = int(input("Número: "))
if n == 0:
    print(1)
else:
    n = abs(n)
    c = 0
    while n > 0:
        c += 1
        n //= 10
    print(c)

    Salida esperada (ejemplo)
    Entrada: Número: 12345 → Salida: 5

## 35) MCD por restas

<details><summary>Mostrar solución</summary>

```python

b = int(input("B: "))
a, b = abs(a), abs(b)
while a != b:
    if a > b:
        a -= b
    else:
        b -= a
print(a)

    Salida esperada (ejemplo)

    t = ""
    for ch in s.lower():
        if ch != ' ':
            t += ch
    inv = ""
    for ch in t:
        inv = ch + inv
    return t == inv
