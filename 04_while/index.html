    04 · Repetición con while¶

    🧩 Resumen de estructuras de control: secuencia, selección y repetición¶

    Tipo Palabra clave Propósito Ejemplo breve
    Secuencia — Ejecutar instrucciones en orden a = 5; b = a + 2; print(b)
    Selección if / elif / else Elegir entre rutas según una condición if x>0: print("positivo")
    Repetición (definida) for Repetir un número conocido de veces for i in range(5): print(i)
    Repetición (indefinida) while Repetir mientras una condición sea verdadera while n>0: n -= 1

    🔍 Qué es un while¶

    El bucle while permite repetir instrucciones mientras una condición se cumpla.
    Cuando la condición deja de ser verdadera, el ciclo termina.

    while condicion:
    # bloque

    Ejemplo simple:

    i = 1
while i <= 3:
    print(i)
    i += 1
# salida: 1 2 3

    ⚙️ Diferencias entre for y while¶

    for while
    Se usa cuando sabes cuántas veces repetir Se usa cuando no sabes cuántas veces, pero sabes la condición
    Recorre secuencias o rangos Evalúa una condición booleana
    Menos riesgo de bucle infinito Requiere actualizar variables internas

    🧠 Cómo funciona internamente¶

    1. Se evalúa la condición.
    2. Si es True, se ejecuta el bloque.
    3. Al terminar el bloque, se vuelve a evaluar la condición.
    4. Si es False, el bucle termina.

    Si la condición nunca cambia o no se vuelve falsa, el bucle será infinito.

    ⚠️ Cuidados importantes¶

    Un error común es olvidar modificar las variables dentro del while, lo que genera bucles infinitos:

    x = 0
while x < 3:
    print(x)  # bucle infinito: x nunca cambia

    💡 Ejemplos prácticos de uso¶

    Ejemplo 1: Contador ascendente¶

    i = 1
while i <= 5:
    print(i)
    i += 1
    📘 Este programa imprime los números del 1 al 5. La variable i se incrementa en cada iteración.

    Ejemplo 2: Solicitar contraseña¶

    clave = ""
while clave != "python123":
    clave = input("Contraseña: ")
print("Acceso concedido ✅")
    📘 Aquí el bucle se repite hasta que la contraseña ingresada sea la correcta.

    Ejemplo 3: Leer hasta condición de salida¶

    nombre = ""
while nombre != "fin":
    nombre = input("Ingrese un nombre (o ingrese la palabra fin para terminar): ")
    📘 Este patrón es común en bucles controlados por una palabra centinela.

    Ejemplo 4: Bucle con break¶

    while True:
    texto = input("Texto (escriba 'salir' para terminar): ")
    if texto == "salir":
        break
    print("Usted escribió:", texto)
    📘 Aquí el bucle se detiene cuando el usuario escribe “salir”, gracias al uso de break.

    Ejemplo 5: Validación de entrada¶

    n = -1
while n <= 0:
    n = int(input("Ingrese un número positivo: "))
print("Número aceptado:", n)
    📘 Este while garantiza que el valor ingresado sea válido antes de continuar el programa.

    🧮 Ejercicios con while¶

    Cada ejercicio incluye un requerimiento explicado claramente y su solución oculta en un bloque <details>.

    A. While simple¶

    E1. Contador del 1 al 10¶

    Requerimiento: Escribe un programa que muestre los números del 1 al 10 en orden ascendente.
    Debe usar un bucle while y una variable que se incremente en cada iteración.

    Ver solución 
    n = 1
while n <= 10:
    print(n)
    n += 1

    E2. Cuenta regresiva desde 10¶

    Requerimiento: Solicita al usuario un número y muestra una cuenta regresiva desde ese valor hasta 1.
    Utiliza while y resta 1 en cada iteración.

    Ver solución 
    n = int(input("Número inicial: "))
while n >= 1:
    print(n)
    n -= 1
print("¡Despegue! 🚀")

    E3. Suma acumulada¶

    Requerimiento: Solicita un número N y calcula la suma de todos los números desde 1 hasta N.
    El resultado se muestra al final del programa.

    Ver solución 
    N = int(input("Ingrese N: "))
i = 1
suma = 0
while i <= N:
    suma += i
    i += 1
print("La suma es:", suma)

    E4. Promedio hasta cero¶

    Requerimiento: Pide números al usuario hasta que ingrese 0.
    El programa debe calcular y mostrar el promedio de los números ingresados (sin contar el cero).

    Ver solución 
    suma = 0
cont = 0
n = int(input("Ingrese un número (0 para terminar): "))
while n != 0:
    suma += n
    cont += 1
    n = int(input("Ingrese otro número (0 para terminar): "))
if cont > 0:
    print("Promedio:", suma / cont)
else:
    print("No se ingresaron datos")

    E5. Validar contraseña¶

    Requerimiento: Crea un programa que pida una contraseña y repita la solicitud hasta que el usuario escriba "segura123".
    Luego, muestra un mensaje de acceso permitido.

    Ver solución 
    clave = ""
while clave != "segura123":
    clave = input("Ingrese la contraseña: ")
print("Acceso permitido")

    B. While con if¶

    E6. Contar positivos¶

    Requerimiento: Solicita 10 números y cuenta cuántos son positivos.
    Debe mostrar el total al final.

    Ver solución 
    i = 0
positivos = 0
while i < 10:
    n = int(input("Número: "))
    if n > 0:
        positivos += 1
    i += 1
print("Cantidad de positivos:", positivos)

    E7. Leer hasta número par¶

    Requerimiento: Solicita números hasta que el usuario ingrese un número par.
    Al finalizar, muestra el total de números impares ingresados antes del par.

    Ver solución 
    cont = 0
n = int(input("Ingrese un número: "))
while n % 2 != 0:
    cont += 1
    n = int(input("Ingrese otro número: "))
print("Impares ingresados antes del par:", cont)

    E8. Contar múltiplos de 5¶

    Requerimiento: Pide números enteros hasta ingresar -1.
    Cuenta cuántos fueron múltiplos de 5.

    Ver solución 
    cont = 0
n = int(input("Número (-1 para salir): "))
while n != -1:
    if n % 5 == 0:
        cont += 1
    n = int(input("Número (-1 para salir): "))
print("Múltiplos de 5:", cont)

    E9. Números positivos y negativos¶

    Requerimiento: Pide al usuario números hasta que escriba 0.
    Cuenta cuántos son positivos y cuántos negativos.

    Ver solución 
    pos = neg = 0
n = int(input("Número (0 para terminar): "))
while n != 0:
    if n > 0:
        pos += 1
    else:
        neg += 1
    n = int(input("Número (0 para terminar): "))
print("Positivos:", pos, "Negativos:", neg)

    E10. Adivina el número¶

    Requerimiento: El programa tiene un número secreto (por ejemplo, 15).
    El usuario debe adivinarlo. Si el número ingresado es menor o mayor, el programa lo indica hasta que acierte.

    Ver solución 
    secreto = 15
n = None
while n != secreto:
    n = int(input("Adivina el número: "))
    if n < secreto:
        print("Demasiado bajo")
    elif n > secreto:
        print("Demasiado alto")
print("¡Correcto!")

    C. While con if / else¶

    E11. Determinar si los números son pares o impares¶

    Requerimiento: Solicitar al usuario que ingrese números enteros hasta que escriba 0.
    Por cada número ingresado, indicar si es par o impar.

    Ver solución 
    n = int(input("Número (0 para salir): "))
while n != 0:
    if n % 2 == 0:
        print("Es par")
    else:
        print("Es impar")
    n = int(input("Número (0 para salir): "))
print("Programa finalizado")

    E12. Calcular el factorial de un número¶

    Requerimiento: Solicitar un número entero positivo y calcular su factorial usando un while.

    Ver solución 
    n = int(input("Ingrese un número: "))
fact = 1
i = 1
while i <= n:
    fact *= i
    i += 1
print("El factorial de", n, "es", fact)

    E13. Validar contraseña con mensaje de error¶

    Requerimiento: Permitir hasta 3 intentos de contraseña. Mostrar un mensaje de error en cada intento fallido.

    Ver solución 
    clave = ""
intentos = 0
while clave != "python123" and intentos < 3:
    clave = input("Ingrese la contraseña: ")
    if clave != "python123":
        print("Contraseña incorrecta.")
    intentos += 1
if clave == "python123":
    print("Acceso concedido ✅")
else:
    print("Cuenta bloqueada ❌")

    E14. Verificar múltiplos de 3¶

    Requerimiento: Leer números hasta que se ingrese un número negativo.
    Mostrar cuántos fueron múltiplos de 3 y cuántos no.

    Ver solución 
    mult3 = no_mult3 = 0
n = int(input("Número (negativo para salir): "))
while n >= 0:
    if n % 3 == 0:
        mult3 += 1
    else:
        no_mult3 += 1
    n = int(input("Número (negativo para salir): "))
print("Múltiplos de 3:", mult3, "| No múltiplos:", no_mult3)

    E15. Promedio de pares e impares¶

    Requerimiento: Pedir números hasta ingresar 0. Calcular por separado el promedio de números pares e impares.

    Ver solución 
    suma_par = suma_imp = cont_par = cont_imp = 0
n = int(input("Número (0 para salir): "))
while n != 0:
    if n % 2 == 0:
        suma_par += n
        cont_par += 1
    else:
        suma_imp += n
        cont_imp += 1
    n = int(input("Número (0 para salir): "))
print("Promedio pares:", suma_par/cont_par if cont_par>0 else 0)
print("Promedio impares:", suma_imp/cont_imp if cont_imp>0 else 0)

    D. While con if / elif / else¶

    E16. Clasificar temperatura¶

    Requerimiento: Leer temperaturas hasta ingresar -100. Clasificar cada una como “Baja” (<10), “Media” (10–25) o “Alta” (>25).

    Ver solución 
    t = float(input("Temperatura (-100 para salir): "))
while t != -100:
    if t < 10:
        print("Baja")
    elif t <= 25:
        print("Media")
    else:
        print("Alta")
    t = float(input("Temperatura (-100 para salir): "))

    E17. Clasificación de notas¶

    Requerimiento: Pedir notas entre 1 y 7. Mostrar “Insuficiente”, “Suficiente” o “Sobresaliente”. Salir al ingresar 0.

    Ver solución 
    nota = float(input("Nota (0 para salir): "))
while nota != 0:
    if nota < 4:
        print("Insuficiente")
    elif nota < 6:
        print("Suficiente")
    else:
        print("Sobresaliente")
    nota = float(input("Nota (0 para salir): "))

    E18. Clasificar edades¶

    Requerimiento: Leer edades hasta ingresar -1. Clasificar como “niño”, “adulto” o “adulto mayor”.

    Ver solución 
    edad = int(input("Edad (-1 para salir): "))
while edad != -1:
    if edad < 18:
        print("Niño/a")
    elif edad < 65:
        print("Adulto/a")
    else:
        print("Adulto/a mayor")
    edad = int(input("Edad (-1 para salir): "))

    E19. Contador de categorías¶

    Requerimiento: Leer números entre 1 y 100 hasta ingresar 0. Contar cuántos son menores a 50, iguales a 50 o mayores.

    Ver solución 
    men = ig = may = 0
n = int(input("Número (0 para salir): "))
while n != 0:
    if n < 50:
        men += 1
    elif n == 50:
        ig += 1
    else:
        may += 1
    n = int(input("Número (0 para salir): "))
print("Menores:", men, "Iguales:", ig, "Mayores:", may)

    E20. Juego de adivinanza avanzado¶

    Requerimiento: El número secreto es 42. Indica “muy bajo”, “bajo”, “alto” o “muy alto” según la diferencia.

    Ver solución 
    secreto = 42
n = -1
while n != secreto:
    n = int(input("Adivina el número: "))
    if n < secreto - 10:
        print("Muy bajo")
    elif n < secreto:
        print("Bajo")
    elif n > secreto + 10:
        print("Muy alto")
    elif n > secreto:
        print("Alto")
print("¡Correcto!")

    E. While anidado¶

    E21. Tabla de multiplicar¶

    Requerimiento: Mostrar las tablas de multiplicar del 1 al 5. Usa dos bucles while anidados.

    Ver solución 
    i = 1
while i <= 5:
    j = 1
    while j <= 10:
        print(i, "x", j, "=", i*j)
        j += 1
    print("-----")
    i += 1

    E22. Imprimir patrón de asteriscos¶

    Requerimiento: Imprimir un triángulo de asteriscos de 5 filas.

    Ver solución 
    i = 1
while i <= 5:
    j = 1
    while j <= i:
        print("*", end="")
        j += 1
    print()
    i += 1

    E23. Sumar matrices 3x3¶

    Requerimiento: Solicitar valores para dos matrices 3x3 y mostrar su suma.

    Ver solución 
    i = 0
A, B, C = [], [], []
while i < 3:
    filaA, filaB = [], []
    j = 0
    while j < 3:
        filaA.append(int(input(f"A[{i}][{j}]: ")))
        filaB.append(int(input(f"B[{i}][{j}]: ")))
        j += 1
    A.append(filaA)
    B.append(filaB)
    i += 1
for i in range(3):
    fila = []
    for j in range(3):
        fila.append(A[i][j] + B[i][j])
    C.append(fila)
print("Resultado:", C)

    F. While con break y continue¶

    E24. Validar rango de número¶

    Requerimiento: Pedir un número entre 1 y 10. Repetir hasta que esté dentro del rango.

    Ver solución 
    while True:
    n = int(input("Ingrese un número (1-10): "))
    if 1 <= n <= 10:
        break
    print("Fuera de rango. Intente nuevamente.")
print("Número válido:", n)

    E25. Saltar números pares¶

    Requerimiento: Mostrar números del 1 al 10, omitiendo los pares.

    Ver solución 
    n = 0
while n < 10:
    n += 1
    if n % 2 == 0:
        continue
    print(n)

    E26. Suma hasta superar 100¶

    Requerimiento: Pedir números y sumarlos hasta que la suma total supere 100.

    Ver solución 
    total = cont = 0
while total <= 100:
    n = float(input("Número: "))
    total += n
    cont += 1
print("Se ingresaron", cont, "números. Total:", total)

    E27. Login con break¶

    Requerimiento: Validar usuario y contraseña hasta acertar o escribir "salir".

    Ver solución 
    while True:
    user = input("Usuario: ")
    pwd = input("Contraseña: ")
    if user == "admin" and pwd == "1234":
        print("Bienvenido")
        break
    elif user == "salir":
        print("Cerrando sesión")
        break
    else:
        print("Credenciales incorrectas.")

    G. Aplicaciones prácticas¶

    E28. Simular carga de batería¶

    Requerimiento: Mostrar porcentaje de batería desde 0% hasta 100% de 10 en 10.

    Ver solución 
    carga = 0
while carga <= 100:
    print("Batería:", carga, "%")
    carga += 10

    E29. Generar serie Fibonacci¶

    Requerimiento: Generar los primeros 10 números de la serie Fibonacci.

    Ver solución 
    a, b, i = 0, 1, 0
while i < 10:
    print(a)
    a, b = b, a + b
    i += 1

    E30. Contar dígitos de un número¶

    Requerimiento: Solicitar un número y mostrar cuántos dígitos tiene.

    Ver solución 
    n = int(input("Número: "))
cont = 0
while n != 0:
    n //= 10
    cont += 1
print("Cantidad de dígitos:", cont)

    E31. Verificar número primo¶

    Requerimiento: Determinar si un número es primo.

    Ver solución 
    n = int(input("Número: "))
div = 2
es_primo = True
while div < n:
    if n % div == 0:
        es_primo = False
        break
    div += 1
print("Es primo" if es_primo else "No es primo")

    E32. Invertir número¶

    Requerimiento: Invertir los dígitos de un número entero.

    Ver solución 
    n = int(input("Número: "))
inv = 0
while n != 0:
    inv = inv * 10 + n % 10
    n //= 10
print("Número invertido:", inv)

    E33. Contar vocales en frase¶

    Requerimiento: Pedir una frase y contar vocales.

    Ver solución 
    frase = input("Frase: ")
i = 0
vocales = 0
while i < len(frase):
    if frase[i].lower() in "aeiou":
        vocales += 1
    i += 1
print("Vocales:", vocales)

    E34. Control de intentos¶

    Requerimiento: Permitir hasta 5 intentos para adivinar una clave secreta.

    Ver solución 
    clave = "python"
intentos = 0
while intentos < 5:
    c = input("Ingrese la clave: ")
    if c == clave:
        print("Correcto")

    intentos += 1
else:

    E35. Calcular promedio de edades¶

    Requerimiento: Pedir edades hasta ingresar -1 y mostrar promedio.

    Ver solución 
    suma = cont = 0
edad = int(input("Edad (-1 para salir): "))
while edad != -1:
    suma += edad
    cont += 1
    edad = int(input("Edad (-1 para salir): "))
print("Promedio:", suma/cont if cont>0 else 0)

    E36. Simular reloj digital¶

    Requerimiento: Mostrar la hora desde 0:0 hasta 0:59 en formato mm:ss.

    Ver solución 
    m = 0
while m < 60:
    s = 0
    while s < 60:
        print(f"00:{m:02}:{s:02}")
        s += 1
    m += 1

    E37. Contador de palabras¶

    Requerimiento: Solicitar texto y contar cuántas palabras contiene.

    Ver solución 
    texto = input("Texto: ").strip()
cont = 0
i = 0
while i < len(texto):
    if texto[i] == " ":
        cont += 1
    i += 1
print("Palabras:", cont + 1)

    E38. Convertir binario a decimal¶

    Requerimiento: Pedir un número binario (solo 0 y 1) y convertirlo a decimal.

    Ver solución 
    binario = input("Número binario: ")
i = len(binario) - 1
pot = 1
decimal = 0
while i >= 0:
    if binario[i] == "1":
        decimal += pot
    pot *= 2
    i -= 1
print("Decimal:", decimal)

    E39. Serie de cuadrados¶

    Requerimiento: Mostrar los cuadrados de los números del 1 al 10.

    Ver solución 
    i = 1
while i <= 10:
    print(i, "al cuadrado es", i*i)
    i += 1

    E40. Contador total de letras¶

    Requerimiento: Pedir una palabra y contar cuántas letras contiene (sin usar len()).

    Ver solución 
    palabra = input("Palabra: ")
cont = 0
for _ in palabra:
    cont += 1
print("Cantidad de letras:", cont)

    ✅ Recomendaciones finales¶

    • Usa while cuando no conoces cuántas repeticiones serán necesarias.
    • Asegúrate de modificar variables internas dentro del bucle para evitar bucles infinitos.
    • Prefiere for cuando el número de iteraciones es conocido o definido.
    • Combina while con if para construir programas interactivos (menús, validaciones, etc.).
