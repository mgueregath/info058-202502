    05 · Listas en Python — INFO058¶

    🧠 ¿Qué es una lista?¶

    Una lista es una estructura de datos mutable y ordenada que permite guardar varios elementos (posiblemente de distintos tipos) en una sola variable.

    vacia = []
numeros = [10, 20, 30]
mixta = [1, "dos", True, 3.14]
    • Mutable: puedes cambiar, agregar o quitar elementos.
    • Ordenada: respeta el orden de inserción.
    • Indexada: el primer elemento está en el índice 0.

    ✨ Creación y acceso básico¶

    a = [5, 8, 13, 21]
print(a[0])   # 5 (primer elemento)
print(a[1])   # 8
print(a[-1])  # 21 (último)
print(a[-2])  # 13 (penúltimo)

    Slicing (rebanado): lista[inicio:fin:paso] (no incluye fin)

    b = [0, 1, 2, 3, 4, 5, 6]
print(b[2:5])     # [2, 3, 4]
print(b[:3])      # [0, 1, 2]
print(b[4:])      # [4, 5, 6]
print(b[::2])     # [0, 2, 4, 6]
print(b[::-1])    # [6, 5, 4, 3, 2, 1, 0] (invertida)

    🧩 Modificación de elementos¶

    c = ["a", "b", "c"]
c[1] = "B"            # reemplazar
print(c)              # ['a', 'B', 'c']

c[0:2] = ["x", "y"]   # reemplazar porciones
print(c)              # ['x', 'y', 'c']

    ➕ Agregar y quitar elementos (métodos)¶

    Método Uso Efecto
    append(x) L.append(10) Agrega al final
    extend(iterable) L.extend([30,40]) Agrega varios al final
    insert(i, x) L.insert(1, 99) Inserta en posición i
    pop([i]) L.pop() / L.pop(0) Quita y retorna el último o índice i
    remove(x) L.remove(3) Quita la primera ocurrencia de x
    clear() L.clear() Deja la lista vacía 
    L = [10, 20]
L.append(30)          # [10, 20, 30]
L.extend([40, 50])    # [10, 20, 30, 40, 50]
L.insert(1, 15)       # [10, 15, 20, 30, 40, 50]
L.remove(30)          # [10, 15, 20, 40, 50]
ultimo = L.pop()      # quita 50, L queda [10, 15, 20, 40]
primero = L.pop(0)    # quita 10, L queda [15, 20, 40]

    ⚠️ remove(x) lanza error si x no existe. Úsalo con verificación previa: if x in L: L.remove(x).

    🔎 Búsqueda, conteo y orden¶

    Método Ejemplo Resultado
    index(x) [2,4,2].index(2) 0 (primer índice donde aparece)
    count(x) [2,4,2].count(2) 2
    sort() L.sort() Ordena in place
    sorted(L) sorted(L) Devuelve una copia ordenada
    reverse() L.reverse() Invierte in place 
    L = [3, 1, 4, 1, 5]
print(L.count(1))    # 2
print(L.index(4))    # 2
print(sorted(L))     # [1, 1, 3, 4, 5]
L.sort()
print(L)             # [1, 1, 3, 4, 5]
L.reverse()
print(L)             # [5, 4, 3, 1, 1]

    🔁 Recorridos (for / while)¶

    frutas = ["pera", "manzana", "kiwi"]

# for directo
for f in frutas:
    print(f)

# for con índice
for i in range(len(frutas)):
    print(i, frutas[i])

# while
i = 0
while i < len(frutas):
    print(frutas[i])
    i += 1

    🧪 Comparación y pertenencia¶

    L = [1, 2, 3]
print(2 in L)          # True
print(4 not in L)      # True
print([1,2] < [1,3])   # True (lexicográfica)

    🧱 Listas anidadas (matrices simples)¶

    mat = [
    [1, 2, 3],
    [4, 5, 6]
]
print(mat[0][1])     # 2

# recorrer matriz
for fila in mat:
    for x in fila:
        print(x, end=" ")
    print()

    🧰 Copias y alias (¡muy importante!)¶

    A = [1, 2, 3]
B = A          # ❌ NO copia: B referencia A
B.append(4)
print(A)       # [1, 2, 3, 4]  (también cambió)

# ✅ Copias reales:
C = A[:]                    # slicing
D = list(A)                 # constructor
E = A.copy()                # método copy()

C.append(99)
print(A)   # no cambia
print(C)   # copia con 99

    Para anidadas profundas, usar copy.deepcopy (importando copy).

    🧷 Unir y dividir (join / split)¶

    # de lista de str → str
tokens = ["uno", "dos", "tres"]
s = "-".join(tokens)              # "uno-dos-tres"

# de str → lista de str
linea = "a,b,c,,d"
partes = linea.split(",")         # ['a','b','c','','d']

    🧠 List Comprehensions (listas por comprensión)¶

    Manera compacta de construir listas a partir de iterables.

    # cuadrados de 1..5
cuadrados = [x*x for x in range(1, 6)]   # [1, 4, 9, 16, 25]

# pares 0..10
pares = [n for n in range(11) if n % 2 == 0]  # [0,2,4,6,8,10]

# normalizar texto a minúsculas si tiene letras
palabras = ["Hola", "MUNDO", "123"]
min_palabras = [p.lower() for p in palabras if p.isalpha()]  # ['hola','mundo']

    🚩 Errores comunes y tips¶

    • IndexError: acceder a índices fuera de rango (L[100] en una lista pequeña).
    • ValueError con remove/index si el elemento no existe.
    • Mutabilidad: pasar listas a funciones las modifica si cambias sus elementos.
    • Copias reales vs alias: usa L[:], list(L) o L.copy().
    • sort ordena in place y devuelve None; usa sorted(L) si necesitas una nueva lista.

    16) Particionar por signo¶

    Escriba un codigo en python que, dada una lista de enteros, cree dos listas: negativos y no negativos. Imprima ambas.

    17) Rotación a la derecha (1 paso)¶

    Escriba un codigo en python que rote una lista una posición a la derecha (el último pasa al primero).

    Mostrar solución 
    L = [int(input(": ")) for _ in range(int(input("N: ")))]
if len(L) > 0:
    ultimo = L[-1]
    # desplazar hacia la derecha
    i = len(L) - 1
    while i > 0:
        L[i] = L[i-1]
        i -= 1
    L[0] = ultimo
print(L)

    19) Plano: matriz → lista¶

    filas = int(input("filas: "))
cols = int(input("cols: "))

for i in range(filas):
    fila = []
    for j in range(cols):

for fila in mat:

        plana.append(x)

    20) Palabras largas¶

    Escriba un codigo en python que lea un texto, lo divida por espacios en una lista y cree otra lista con palabras de longitud ≥ m.

    Mostrar solución 
    texto = input("texto: ").strip()
m = int(input("m: "))
palabras = [p for p in texto.split(" ") if p != ""]
largas = []
for p in palabras:
    if len(p) >= m:
        largas.append(p)
print(largas)

    ✅ Mini–desafíos (rápidos)¶

    1. Pedir N enteros, imprimir solo los que están en posiciones pares (0,2,4,…).
    2. Leer una lista y producir otra sin elementos repetidos (manteniendo el primer encuentro).
    3. Pedir N palabras y ordenarlas por longitud (si empatan, por orden alfabético).
    4. Dada una lista de enteros, construir otra con 1 si el elemento es par y 0 si es impar.
    5. Dada una lista, crear otra con los acumulados ([a, a+b, a+b+c, ...]).
    Mostrar soluciones 
    # 1
N = int(input("N: "))
L = [int(input(": ")) for _ in range(N)]
for i in range(0, len(L), 2):
    print(L[i])

# 2
N = int(input("N: "))
L = [int(input(": ")) for _ in range(N)]
vistos = []
sin_rep = []
for x in L:
    if x not in vistos:
        sin_rep.append(x)
        vistos.append(x)
print(sin_rep)

# 3
N = int(input("N: "))
L = [input(": ") for _ in range(N)]
# orden estable por longitud y luego alfabético
L.sort()               # primero alfabético
L.sort(key=len)        # luego por largo
print(L)

# 4
N = int(input("N: "))
L = [int(input(": ")) for _ in range(N)]
binaria = [1 if x % 2 == 0 else 0 for x in L]
print(binaria) 

# 5
N = int(input("N: "))
L = [int(input(": ")) for _ in range(N)]
acc = []
s = 0
for x in L:
    s += x
    acc.append(s)
print(acc)
